# 1.3.1

- Полностью переработано стартовое меню: теперь оно запускается через Python и не показывает служебные `echo`.
- `START_HERE.bat` стал тонким запускателем.
- Добавлены явные статусы долгих операций, чтобы было видно, что программа не зависла.
- Улучшены сообщения при подключении к кабинету, сканировании кампаний и повторном контроле после удаления.
- Рабочая API-логика создания, удаления и проверки кампаний не изменялась.

# 1.3.0

- Добавлен `START_HERE.bat` — единое меню для пользователя без знания командной строки.
- Добавлен генератор `campaigns.json` из простого списка `SKU;СТАВКА`.
- Поддерживается вставка двух колонок напрямую из Excel через TAB.
- Поддерживаются ставки с точкой и запятой (`7.5` / `7,5`).
- Генератор блокирует дубли SKU и некорректные ставки до записи JSON.
- Добавлен `09_MAKE_CAMPAIGNS_JSON.bat`.
- Добавлен безопасный пример `data/campaigns_input.example.txt`.
- Рабочий `data/campaigns_input.txt` исключён из Git.

# 1.2.0

- Добавлено безопасное удаление кампаний по явному `campaign_id`.
- Добавлен режим предварительной проверки без удаления.
- Массовое удаление блокируется, если хотя бы один ID не найден.
- Для запуска удаления требуется точное подтверждение `DELETE N`.
- После удаления автоматически выполняется контрольный экспорт кампаний.
- Добавлен `reports/delete_report.csv`.
- Локальный `data/campaigns_to_delete.json` исключён из Git.
