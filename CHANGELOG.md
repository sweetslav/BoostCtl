# История изменений

## 1.1.0 — 2026-08-07

- добавлена проверка фактических кампаний Яндекс Маркета перед созданием;
- защита от дублей теперь работает по SKU, а не по полному названию кампании;
- добавлена команда `preflight`;
- добавлена команда `export`;
- исправлено извлечение SKU из названия кампании;
- добавлен экспорт `reports/campaigns_from_yandex.csv`;
- программа показывает количество уже существующих и новых SKU до запуска;
- добавлен статус `SKIPPED_EXISTS`;
- добавлены тесты для разбора названий и поиска дублей;
- версия пакета обновлена до 1.1.0.
