# Буст показов — создание кампаний

Патч содержит 36 SKU из согласованного списка. Один SKU (`21210689/9#1`) уже создан вручную, поэтому в `data/shows_campaigns.json` находятся **35 новых кампаний**.

Для всех новых кампаний:
- одна кампания = один SKU;
- дневной бюджет = 300 ₽;
- название = `SKU | текущая дата`.

Безопасный порядок запуска:

1. `14_SHOWS_DRY_RUN_ONE.bat` — найти offerId первого SKU, ничего не создавать.
2. `15_SHOWS_CREATE_ONE.bat` — создать одну кампанию.
3. Проверить её в кабинете.
4. `16_SHOWS_CREATE_TEN.bat` — обработать первые 10 SKU. Уже созданный на шаге 2 SKU автоматически пропустится по локальному отчёту.
5. `17_SHOWS_CREATE_REMAINING.bat` — обработать оставшиеся SKU начиная с позиции 11.

Отчёт:
`reports/shows_create_report.csv`

Встроена локальная защита: SKU со статусом `CREATED` в этом отчёте повторно не создаются.

Важно: полноценная проверка дублей по фактическому списку кампаний «Буста показов» будет отдельной следующей функцией. На текущем этапе задача — безопасно создать этот пакет.
