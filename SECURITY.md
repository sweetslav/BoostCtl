# Security Policy

Не публикуйте cookies, `Session_id`, `sessionid2`, `sk`, HAR-файлы и содержимое `browser_profile`.

При случайной публикации:
1. завершите активные сессии Яндекса;
2. войдите в аккаунт заново;
3. удалите секреты из истории Git;
4. замените опубликованные файлы безопасными примерами.
