# Quick Start

1. Run `00_INSTALL.bat` once.
2. Fill `data/campaigns.json` or `data/shows_campaigns.json`.
3. Start `START_BOOSTCTL.bat`.
4. Choose an action, review its preview, then use the existing typed confirmation for an apply operation.
5. View durable operation history in menu item `3`.

Older BAT files remain advanced compatibility commands. SQLite in `local_data/boostctl.db` records local operation history; it is not factual Yandex inventory.
